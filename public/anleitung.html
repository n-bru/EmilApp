Einrichtung auf deinem Handy

Eine Web-Seite darf dein Hintergrundbild nicht selbst ändern. Darum holt eine Automation auf deinem Handy das aktuelle Bild von dieser Adresse ab:

Du richtest das einmal ein und kannst es jederzeit wieder löschen. Nichts passiert ohne dich.

iPhone (Kurzbefehle)

  1. App Kurzbefehle öffnen → unten Automation → + → Tageszeit, z. B. 8:00 Uhr, Täglich.
  2. Sofort ausführen wählen, „Beim Ausführen benachrichtigen“ ausschalten.
  3. Aktion Inhalte von URL abrufen hinzufügen. URL: die Adresse oben. Methode: GET.
  4. Aktion Hintergrundbild festlegen hinzufügen. Eingabe: Inhalte von URL. Bei „Anzeigen“ Sperrbildschirm und/oder Home-Bildschirm wählen. „Vorschau anzeigen“ ausschalten.
  5. Speichern. Mit Ausführen in der Automation kannst du es sofort testen.

Tipp: Bei der Aktion „Hintergrundbild festlegen“ ggf. „Perspektivzoom“ aus und „Weichzeichnen“ aus.

Android (MacroDroid)

  1. App MacroDroid installieren und die Berechtigungen zulassen.
  2. Neues Makro. Auslöser: Datum/Zeit → Tageszeit (z. B. 8:00 Uhr).
  3. Aktion: Verbindung → HTTP-Anfrage, GET auf die Adresse oben, Antwort in Datei speichern (z. B. /Download/bg.jpg).
  4. Aktion: Gerät → Hintergrundbild setzen mit dieser Datei. Sperrbildschirm und/oder Startbildschirm wählen.
  5. Makro speichern und einmal manuell testen. Bei Akku-Sparmodus MacroDroid von der Optimierung ausnehmen.

Hinweise

  • Das Bild wechselt zur eingestellten Uhrzeit, nicht sofort nach dem Upload.
  • Die Automation braucht Internet (WLAN oder mobile Daten).
  • Ausschalten: Automation bzw. Makro löschen.
